# FOLD 펀딩 페이지

접으면 작아지는 텀블러 'FOLD'를 소개하는 가상의 펀딩 페이지입니다.
제품 소개 페이지를 퍼블리싱하는 연습으로 만들었습니다.

## 프로젝트 정보

- 작업 유형: 개인 작업 (기획, 디자인, 퍼블리싱)
- 사용 기술: HTML, CSS, JavaScript

## 페이지 구성

1. 메인 (제품 소개, 용량 / 무게 / 접은 높이)
2. 펀딩 현황 (달성률, 후원자 수, 남은 기간)
3. 제품 정보 (구조, 크기 비교)
4. 색상 선택 및 소재 정보
5. 브랜드 스토리
6. 하단 고정 바 + 푸터

## 작업한 내용

- 텀블러 이미지는 파일 대신 SVG 도형(`rect`)으로 직접 그렸습니다.
- 펀딩 현황은 게이지 바와 숫자 카드로 한눈에 보이게 구성했습니다.
- 제품 스펙처럼 이름과 값이 짝인 내용은 `dl`, `dt`, `dd` 태그로 마크업했습니다.
- SVG 안에 펼친 모습과 접힌 모습을 각각 만들고, 버튼을 누르면 두 모습이 바뀌도록 구현했습니다.
- 테마 변경과 제품 색상 선택은 기본 JavaScript 클릭 이벤트로 구현했습니다.
- 색상 버튼, 테마 전환 버튼에는 `aria-label`, `aria-pressed`를 넣었습니다.
- CSS를 `base`, `layout`, `sections` 세 파일로 나누어 관리했습니다.

## 폴더 구조

```
fold_funding
├─ index.html
├─ css
│  ├─ base.css      (색상, 기본 스타일)
│  ├─ layout.css    (헤더, 공통 레이아웃)
│  └─ sections.css  (섹션별 스타일)
└─ js
   └─ main.js
```

## 참고

- FOLD는 가상의 제품이며, 펀딩 금액과 후원자 수, 연락처는 모두 예시입니다.
- 실제 결제 기능은 없습니다.
